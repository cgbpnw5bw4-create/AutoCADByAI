# 零件库 (CadLibrary) 与沉淀规则

平台今后要面对大量建模工作。每做一个设计，凡是**下一个设计还会用到**的东西，都要从设计项目里提炼出来，沉淀到零件库或内核；下一个设计直接调用，不再重写、不再重新标定。

## 1. 放在哪一层

| 是什么 | 放到 | 例子 |
|---|---|---|
| 与 SolidWorks API 打交道的通用手段、经实测标定的 API 行为 | 内核 `src/CadKernel` | 新的特征类型 (如扫描、放样)、新的出图规则、新的校核 |
| 可参数化、跨设备复用的零件族 | 零件库 `src/CadLibrary` | 齿轮、轴、辊、带座轴承、型材、法兰 |
| 外购件、标准件的样本模型 (按样本安装尺寸建包络) | 零件库 `Purchased.cs` / 内核 `Fasteners.cs` (GB 紧固件) | 联轴器、伺服电机、导轨滑块、泵阀 |
| 只属于这一台设备的布局、自制件、装配关系 | 设计项目 `src/CadProjects/<设计>` | 某设备的机架、槽体、墙板 |

## 2. 收录门槛 (进入零件库前必须满足)

1. **在真实 SolidWorks 中建出来过**，并通过内核三道防线 (特征体积、孤立草图、实体数)。
2. **参与过一次回归样例的完整运行** (`cad run`，run.json 为 passed)，或注明"来源已验证、本平台尚未回归"。
3. **参数化**：尺寸由参数推出，不写死某台设备的坐标；零件代号用通用编号 (如 `WG-008`)，不带设备前缀。
4. **注明来源与局部坐标约定** (安装面在哪、轴线朝哪)，写在类或条目的注释里。
5. **纯计算部分有单元测试** (如齿形与原实现逐段对照)。

建议时机：某个零件族**第二次**被不同设计用到时提炼。第一次可以先写在设计项目里。

## 4. 已知局限

- **渐开线齿廓**：齿根过渡用 0.38m 圆弧近似 (非展成曲线)，齿根应力只作量级评估；α=20° 时 **z=30~41 无法生成** (齿根圆略小于基圆，圆角与径向线不能相切；原 Python 版本同样如此，参数校验阶段即报错)。需要这些齿数时，应改为展成齿根并补测试。
- **外购件**：型号为选型建议，模型是按样本关键安装尺寸建的包络，质量取样本值；采购前须按供应商最新样本核对安装尺寸。
- **紧固件**：螺纹按公称直径光杆简化表达 (GB/T 4459.1)，不建牙型。
- **自动出图** (内核 `Drawings.cs`)：
  - 板类、盘类零件：标外形尺寸、孔坐标表与孔径；**凸台、台阶等非孔特征的定位尺寸不自动标注**，需要时在设计项目里补，或在技术要求中说明。
  - 回转体零件 (`DrwType = "turn"`)：剖视图标直径与轴向尺寸。齿轮等非回转特征会投影出伪直径 → 用 `Part.Dias` 限定只标哪些直径，齿轮参数放参数表 (`Part.Table`)。
  - 形位公差、局部粗糙度不自动标注，写进技术要求 (`Part.Notes`)；图上只有"其余 Ra"。
  - 装配图：主 / 俯 / 轴测视图 + 外形尺寸 + 序号 + 明细表，不标安装与配合尺寸。
  - 没有任何尺寸的零件图在图纸目录中标"待补尺寸"，`工程图生成` 校核不通过。

## 5. 新设计的推荐做法

1. 先查本表和 `docs/api_calibration.md`，能复用的直接调用。
2. 在 `src/CadProjects/<设计>/` 新建设计项目，继承 `CadProject`，实现参数校验、零件、装配；出图、BOM、干涉、STEP、版面审核由流水线完成。
3. 在 `input/<任务>/design.json` 写参数，`cad run <任务>` 运行，看 `run.json`。
4. 运行通过后，回头检查哪些零件族下次还会用，按第 2 节门槛提炼进零件库，并在本表登记。
