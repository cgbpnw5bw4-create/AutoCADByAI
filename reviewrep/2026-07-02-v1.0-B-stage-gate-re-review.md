## 5. 高优先级问题

### HIGH-001（本轮唯一 HIGH）：REL-1 只修了连接侧，构建/工程图执行阶段仍无超时护栏

- **位置**：[SolidWorksSessionManager.cs:115-137](AI_Mechanical_Engineering_Agent_Platform/src/Workers/SolidWorks/SolidWorksSessionManager.cs:115) `ExecuteWithApplicationAsync`。
- **已修好的部分**（值得肯定）：
  - 连接：`connectTask = Task.Run(ConnectCore, CancellationToken.None); await connectTask.WaitAsync(timeout.Token);`（[:75-76](AI_Mechanical_Engineering_Agent_Platform/src/Workers/SolidWorks/SolidWorksSessionManager.cs:75)）——超时后调用方可控返回；`ReleaseLateConnection`（[:213-237](AI_Mechanical_Engineering_Agent_Platform/src/Workers/SolidWorks/SolidWorksSessionManager.cs:213)）在孤儿任务完成后释放 COM 并吞掉未观察异常。有测试 `SolidWorksSessionManagerReturnsTimeoutWhenComCallIgnoresCancellation`。
  - 断开：worker 侧 `disconnectCts` + `await disconnectTask.WaitAsync(disconnectCts.Token)`（[RealSolidWorksWorker.cs:407-413](AI_Mechanical_Engineering_Agent_Platform/src/Workers/SolidWorks/RealSolidWorksWorker.cs:407)）。
- **仍缺失的部分**：`ExecuteWithApplicationAsync` 直接 `return await action(_application, cancellationToken);`（[:131](AI_Mechanical_Engineering_Agent_Platform/src/Workers/SolidWorks/SolidWorksSessionManager.cs:131)），**没有 `CancelAfter` 也没有 `WaitAsync(timeoutToken)`**。plate 构建（[RealSolidWorksWorker.cs:236](AI_Mechanical_Engineering_Agent_Platform/src/Workers/SolidWorks/RealSolidWorksWorker.cs:236)）与工程图构建（[:196](AI_Mechanical_Engineering_Agent_Platform/src/Workers/SolidWorks/RealSolidWorksWorker.cs:196)）都经它执行；两个 builder 内部虽用 `Task.Run(..., cancellationToken)`，但同步阻塞的 COM 调用不感知 token，调用方仍会无限阻塞。`SolidWorksBuildPlan.cs` 本轮只新增了工程图相关字段，并未新增构建/执行超时。
- **风险**：真实 SolidWorks 在**构建/保存/PDF 导出阶段**最容易弹出模态对话框（重建错误、"覆盖已存在文件？"、特征错误、许可证提示）。这正是 REL-1 最初担心的挂死面，却是本轮唯一没被 `WaitAsync` 覆盖的路径。协议 P0/P3"COM 自动化失控 / 外部应用卡死"。
- **为什么评 HIGH 而非 Blocker**：真实 CAD 默认关闭 + 三重开关；挂死只会停住 self-check，不会产生错误产物或假成功。但它是被点名的 stage-gate 项且修复不对称（连接保护、构建不保护），应尽快补齐。
- **建议修复**：为 `ExecuteWithApplicationAsync` 增加与连接一致的超时：`using var cts = CreateLinkedTokenSource(cancellationToken); cts.CancelAfter(执行超时); var task = Task.Run(() => action(app, cts.Token), CancellationToken.None); return await task.WaitAsync(cts.Token);`，超时时返回结构化失败并调度孤儿清理。建议在 `SolidWorksRuntimeOptions` 增加独立的 `ExecutionTimeoutSeconds`（区别于 `ConnectTimeoutSeconds`）。并补一个"构建阶段 COM 忽略取消 → 超时失败"的回归测试。
