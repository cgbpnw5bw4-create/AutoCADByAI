## 2. 结论理由

**核心理由：V2.0-B 在"能力已建成"与"能力已验证"之间划了一条诚实的线，并用 fail-closed 的机器门禁强制执行它。这是本项目红线（假成功比显式失败更危险）迄今最好的一次落实。**

具体、可验证的依据：

1. **五个通用 Handler 全部标记 `Unverified`，拒绝借用 V1.9 证据。** `SketchHandler` / `ExtrudeBossHandler` / `ExtrudeCutHandler` / `HoleHandler` / `RevolveBossHandler` 的 `ApiEvidence.Status` 全为 `FeatureApiEvidenceStatuses.Unverified`（各文件第 29-35 行）。V2.0-B 边界明写"不把 V1.9 零件族专用证据视为通用 Handler 授权"，代码严格照做。Handler 文档同样诚实：`Features/Hole/api_evidence.md:5` 写明"当前没有被项目接受的通用 Hole API 映射，也没有授权的返回合同"，并在 `:32` 列出提升为 `verified` 的条件。**这是主动放弃"看起来能跑"的诱惑。**

2. **未验证证据在连接 COM 之前阻断整图，且有最强行为证明。** `FeatureHandlerRegistry.ValidateForRealExecution`（`FeatureHandlerRegistry.cs:86-135`）逐节点校验 `ApiEvidence.AllowsRealExecution`（:120-127），任一未验证即拒绝整图；`RealSolidWorksWorker.cs:174-194` 在 COM 连接前调用它，失败即 `Rejected` + `FeatureApiEvidenceInsufficient`，日志 "COM connection was not attempted"。测试 `UnverifiedApiBlocksRealWorkerBeforeComConnection`（V20B:163-207）在**全部真实执行开关打开**（`EnableRealExecution:true`、`DryRun:false`、`IsCiEnvironment:false`、`IsUnitTestEnvironment:false`、`MainWorkflowExecutionEnabled:true`）的条件下断言 `ConnectCount == 0`、`RealCadConnected=false`、`RealCadExecuted=false`。**用行为而非源码顺序证明了门禁有效。**

3. **V1.9 真实路径未被破坏，双路径边界清晰。** 通用路径是 opt-in：仅当 `BuildPlan.ExecutionStrategy == FeatureHandlerGraph` 才走 Handler 图（`RealSolidWorksWorker.cs:155-159`）；V1.9 零件族 builder 走原策略不受影响，并有回归测试 `FamilyGeneratedGraphPreservesLegacyBuilderStrategy`（V20B:210）保护。

4. **环境探针是加法式的，且没有破坏我上轮确认正确的代码。** 新增 `SolidWorksExecutionEnvironmentProbe`（只读探测 OS / `Environment.UserInteractive` / `SldWorks.Application` COM 注册），在 COM 连接前执行，失败即 `Failed` + `real_execution_environment_unavailable`，**不回退 Fake Worker**（`RealSolidWorksWorker.cs:232-253`）。关键是：`ShouldUseRealWorker` 的六条件链**完整保留**，`IsCiEnvironment` / `IsUnitTestEnvironment` 结构性阻断未被移除（`SolidWorksBuildPlan.cs:138-145`）。**Codex 没有因我首轮的错误报告去改动那段正确的代码——我上轮的更正与警告被正确采纳。** 另有 `InjectedSessionManagerCannotRemoveDefaultEnvironmentProbe`（V20A:297）防止通过依赖注入绕过探针。

5. **V2.0-A 图校验完整且前置。** `FeatureGraphRejectsMissingDependencyCycleAndInvalidOrder`、`FeatureGraphProducesStableTopologicalOrder`、`CyclicFeatureGraphIsRejectedBeforeWorkerDispatch`（V20A:185-223，断言 `FeatureDependencyCycle` 在 Worker 派发前拒绝）、`BuildPlanValidatorRejectsTamperedOperationCycle`（防篡改）、三族均能从通用图编译。
