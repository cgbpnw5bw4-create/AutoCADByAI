## 8. CAD / COM / 外部运行时风险评估

- **授权门禁（双层，均 fail-closed）**：
  1. **连接 COM 之前**：`FeatureHandlerRegistry.ValidateForRealExecution` 全图逐节点校验（`RealSolidWorksWorker.cs:174-194` 之后的等价位置），任一节点证据不合格即拒绝整图，日志 "COM connection was not attempted"。
  2. **连接之后、任何建模 API 之前**：`ValidateRuntimeForRealExecution`（`RealSolidWorksWorker.cs:367-394`）比对连接到的 SolidWorks 版本与证据版本，失配即 `Rejected` + 日志 "No modeling API was invoked because the connected SolidWorks version does not match the per-handler evidence"。位置正确——396 行的 `operation_executed: connection_success` 在其后。
- **假成功防护**：✅ 逐特征 `result_object_validated` / `rebuild_passed` / `geometry_change_validated` 三重校验；体积由 `GetMassProperties` 实测并按方向断言（`RealSolidWorksFeatureAdapter.cs:377-407`），容差 `max(1e-12, |before|×1e-9)`；产物要求 `exists && size_bytes>0 && status=="Passed"`。
- **文件 I/O 安全**：✅ 诊断输出写入 `output/solidworks/features/<时间戳>/` 隔离目录，被 `.gitignore` 覆盖；未见覆盖用户源风险。
- **环境依赖声明**：✅ 证据显式记录 `SolidWorksVersion: 33.5.0` 并在运行时强制匹配——把"API 行为随 SW 版本变化"这一真实风险变成了机器可检测项。
- **异常吞掉**：✅ 策略仅捕获 `JsonException` / `IOException` / `UnauthorizedAccessException` 并转为显式 issue（:272-276），不静默通过。
- **日志可定位性**：✅ 失败信息含具体期望值与实际值（如 "expected {currentRevision}, evidence has {…}"、体积 before/after 精确值）。
