## 4. 关键架构改进

### 4.1 Internal Agent 链现在受完整 Quality Loop 保护

```
Gateway → chief-engineer → ChiefEngineerOrchestrator
  → SequentialWorkflowEngine
    → InternalAgentWorkflowStep (mechanical-designer)
      → InternalAgentRouter.InvokeInternalAgentAsync
        → Agent.ExecuteAsync
      → AgentOutputReviewMapper.ToReviewReport
      → Gatekeeper.Evaluate
      → IRetryPolicy.ShouldRetry (if rejected)
      → AuditLog: quality_gate_after_internal_step
    → InternalAgentWorkflowStep (cad-modeler)
    → InternalAgentWorkflowStep (drawing-engineer)
    → InternalAgentWorkflowStep (drawing-reviewer)
  → InternalCollaborationReport (with WorkflowId, StepResults, RetrySummary, FailureReport, HumanApprovalRequest)
→ AgentGatewayHost → QualityGate → GatewayMessageResponse
```

### 4.2 五种 Workflow 结束状态全部覆盖

| 状态 | 触发条件 | 后续 step | 生成物 |
|------|---------|-----------|--------|
| Passed | 所有 step = Passed | 全部执行 | FinalGateDecision |
| Rejected | 超过 MaxRetries 或不可重试 issue | 停止 | RejectReport + FailureReport |
| Failed | GateDecisionResult.Failed | 停止 | FailureReport |
| WaitingForHumanApproval | GateDecisionResult.NeedsHumanApproval | 停止 | HumanApprovalRequest |

### 4.3 RetryPolicy 继承链

```
IRetryPolicy (接口)
  ↑
DefaultRetryPolicy (基类, virtual)
  ↑              ↑
RetryPolicy    ExponentialBackoffRetryPolicy
```
