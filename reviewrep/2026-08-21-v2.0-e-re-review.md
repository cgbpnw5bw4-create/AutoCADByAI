## 3. 新发现的问题

### HIGH-001：回归闸保护能力字段，但没有任何东西保护基线本身

**位置**：`src/PlatformCore/SelfCheckCapabilityRegressionGate.cs`、`docs/self_check_capability_baseline.json`

**问题**：全仓库搜索确认，针对基线的校验只有四项——文件存在、JSON 合法、含 `protected_capabilities` 对象、受保护字段数 ≥ 1。

**没有任何机制阻止把基线里某个字段从 `true` 改成 `false`，也没有任何机制阻止删除字段**（只要还剩一个）。测试 `V20ERegressionGateTests` 只有 2 条，覆盖了「保护字段 true→false 被拒」，但**没有覆盖「基线自身被削弱」**。

**风险**：失败模式只是**上移了一层**。原来是「字段静默回归」，现在变成「基线静默削弱 → 字段随后合法回归」。而且后者更隐蔽：改一个 JSON 布尔值，自检依然全绿，回归闸依然报 Passed。

**为什么这条重要**：本项目的主导风险模式是「锁挡不住新形态」——已连续复发七次。回归闸是为终结该模式而建的，但它自己现在就带着同一个形状的缺口。**下一次迁移遇到保护字段挡路时，把基线改成 false 是阻力最小的路径。**

**建议修复**（按成本排序）：

1. 增加一条测试：断言 `docs/self_check_capability_baseline.json` 中所有 `protected_capabilities` 的值**必须为 true**。基线的语义是「这些能力已达成且不得退化」，false 值没有合法用途，直接禁止即可。成本极低。
2. 增加一条测试：断言基线受保护字段数**只增不减**（记录一个下限常量，或断言当前 9 项均在）。
3. 更强的做法：把基线纳入 `FeatureExecutionEvidencePolicy` 式的 SHA 绑定，改动必须显式声明。此项可延后。

### MEDIUM-001：`feature_graph_template_reuse_supported` 的判据接近恒真

**位置**：`PlatformSelfCheckRunner.cs:2380-2382`

```csharp
var featureGraphTemplateReuseSupported =
    commonFeatureTemplatesExists &&
    regressionModels.All(model => model.Spec.PartType == model.PartType);
```

第二个条件检查每个回归模型的 `Spec.PartType` 是否等于它自己的 `PartType`。而 `PartFamilyRegressionModel(string PartType, CADModelSpec Spec)` 在构造时两者传的是同一个值，因此该条件**恒成立**，是自洽性检查而非模板复用检查。

字段名宣称「FeatureGraph 支持模板复用」，实际只证明了「`CommonFeatureTemplates` 有两个方法存在」。**真实的模板复用（四族共 11 处调用）没有被任何判据覆盖。**

**建议修复**：改为断言四个族的 FeatureGraph 中，由 `CommonFeatureTemplates` 生成的 Sketch/Constraint 数量大于零；或反射统计 `PartFamilyGenericModelFactory` 对模板方法的实际调用结果。

### MEDIUM-002：`regressionModels.Count == 3` 硬编码，主动阻碍补齐第四个族

**位置**：`PlatformSelfCheckRunner.cs:2369`

`partFamilyDefinitionSupported` 要求回归模型数**恰好等于 3**。V2.0-E 实际统一了**四个**族，jacket 却不在回归模型中。若后续补上 jacket，该判据会立刻变 false，**修复正确的事反而导致自检失败**。

任务书 Part 5 原文是「至少包含」三个族，因此当前状态不违反字面要求，但硬编码等号把「至少」写成了「恰好」。

**建议修复**：改为 `regressionModels.Count >= 3` 且覆盖全部已注册零件族；同时把 jacket 补入回归模型。

### LOW-001：`CommonFeatureTemplates` 仅覆盖 2 / 6 个规定模板

规格要求 BaseSketch、ExtrudeBoss、ExtrudeCut、HolePattern、RevolveBase、StepFeature，当前只有 `CreateCircleSketch` 与 `CreateDimensionalConstraint`。机制正确且已投入使用，覆盖面待扩。不阻塞。
