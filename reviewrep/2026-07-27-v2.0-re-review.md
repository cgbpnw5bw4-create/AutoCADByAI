```csharp
private static bool IsCi(Func<string,string?> get) =>            // :147-154
    ParseBool(get("CI")) || ParseBool(get("TF_BUILD")) ||
    ParseBool(get("GITHUB_ACTIONS")) || ParseBool(get("GITLAB_CI")) ||
    !IsNullOrWhiteSpace(get("JENKINS_URL")) ||
    !IsNullOrWhiteSpace(get("TEAMCITY_VERSION")) ||
    !IsNullOrWhiteSpace(get("BUILD_BUILDID"));

private static bool IsUnitTest(Func<string,string?> get)          // :156-175
{
    if (ParseBool(get("SW_UNIT_TEST_MODE")) || ParseBool(get("DOTNET_RUNNING_IN_TEST"))) return true;
    var processName = Path.GetFileNameWithoutExtension(Environment.ProcessPath) ?? "";
    if (processName.Contains("testhost", ...) || processName.Contains("vstest", ...)) return true;
    return AppDomain.CurrentDomain.GetAssemblies()
        .Any(name => name.StartsWith("xunit", ...) || ...);
}
```

- **CI 判据**：`CI` / `GITHUB_ACTIONS` / `GITLAB_CI` / `TF_BUILD` / `JENKINS_URL` / `TEAMCITY_VERSION` / `BUILD_BUILDID` —— 这些全部由 CI 平台**自动注入**，无需任何人记得配置。

## 4. 更正后的安全模型评估

真实执行需要**同时满足全部条件**：

| 条件 | 来源 | 开发机手动跑 | CI / 单测 |
|---|---|---|---|
| `!dryRun` | 请求 | ✅ 默认 false | — |
| `RealExecutionDefaultEnabled` | 常量 true（default-on） | ✅ | ✅ |
| `!DisableRealExecution` | `SW_DISABLE_REAL_EXECUTION` | ✅ 未设 | — |
| `!ForceFakeWorker` | `SW_FORCE_FAKE_WORKER` | ✅ 未设 | — |
| **`!IsCiEnvironment`** | **自动探测 7 种 CI 变量** | ✅ 非 CI | ❌ **自动阻断** |
| **`!IsUnitTestEnvironment`** | **自动探测进程名/程序集** | ✅ 非测试 | ❌ **自动阻断** |

- **所有者要的体验**：开发机手动跑 → 全部满足 → **真实调用 SolidWorks，看得见**。✅
- **自动化安全**：CI 或单测宿主 → `IsCi` / `IsUnitTest` 自动为 true → `EnableRealExecution=false` → 走 preflight-only，**不依赖任何人记得设开关**。✅

这是一个**既满足 default-on 便利、又保持结构性 fail-safe** 的设计。V2.0 在这一点上做得是对的。
