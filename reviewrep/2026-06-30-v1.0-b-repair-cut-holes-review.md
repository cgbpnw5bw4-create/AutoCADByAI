   - **建议**：在下次成功运行后重新生成 evidence 报告以反映当前策略。

2. **保存/导出操作的 DISP_E_TYPEMISMATCH 噪声**（Improvement）。
   - 成功运行（`20260701_022710`）的 `save_sldprt_errors` 和 `export_step_errors` 包含 `save_as_exception: 类型不匹配。(0x80020005 (DISP_E_TYPEMISMATCH))`，但 `Extension.SaveAs` 失败后 fallback（`SaveAs3` 或 `SaveAs`）成功，SLDPRT/STEP 实际存在。
   - **建议**：区分"尝试失败但 fallback 成功"和"最终失败"，将前者降级为 warning。

3. **基准面选择始终先全量失败再通过 feature scan 成功**（Improvement）。
   - 所有诊断报告的 `plane_selection_errors` 都包含 12 个名称候选的全部失败（英文 5 个 + 中文 5 个 + 短名 2 个），然后通过 `feature_scan_preferred` 成功。
   - 中文本地化基准面名称（如"上视基准面"）的 `SelectByID2` 选择始终失败，说明 `SelectByID2` 在当前 SolidWorks 中文环境下对基准面名称不适用。
   - **建议**：将 `feature_scan_preferred` 提升为首选策略，减少不必要的名称尝试。

4. **COM 辅助方法代码重复**（Improvement）。
   - `GetProperty`、`Invoke`、`TryInvoke`、`TryInvokeBool` 等方法在 `SolidWorksPlateFeatureBuilder.cs`、`LateBoundSolidWorksPlateBuilder`（`SolidWorksPlateBuilder.cs:676-722`）、`SolidWorksDiagnosticRunner.cs`（`SolidWorksDiagnosticRunner.cs:597-658`）中重复。
   - **建议**：V1.1 考虑提取公共 COM 工具类，但当前重复不是架构问题。

5. **`CreateThroughHoles` fallback path 退出草图后再尝试**（Improvement，非缺陷）。
   - 活动草图候选（`CreateMacroRecordedActiveSketchFeatureCutCandidates`）失败后，fallback 调用 `ExitSketch(model)` 再重新选择草图。
   - 这是合理的 fallback 设计，但需要在文档中标注：fallback 路径使用了不同的选择策略（退出草图 → 重新选择草图引用 → `FeatureCut4` through-all），与宏录制的活动草图路径不同。
