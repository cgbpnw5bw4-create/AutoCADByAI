## 4. Improvements

以下是不阻塞但建议优化的问题：

### 4.1 self-check 仅做文件存在检查，缺少内容质量验证

- **位置**：`output/reports/platform_self_check_report.json`
- **描述**：当前 self-check 的 V1.0-DOCS-AGENTS 字段（如 `docs_index_exists`、`codex_agents_do_not_replace_project_modules`）只验证文件是否存在或布尔标记是否为 true，不验证文件内容是否真正可执行。
- **建议**：在后续迭代中增加内容质量检查层，例如：
  - 检查 `execution.md` 是否包含执行步骤
  - 检查 `failure_repair.md` 是否包含 failure_stage 表格
  - 检查 `.codex/agents/*.toml` 是否包含 `sandbox_mode` 字段
  - 检查文档是否包含自引用（例如 execution.md 是否正确引用了 failure_repair.md）

### 4.2 缺少 Codex Agent sandbox_mode 的自动化验证

- **位置**：`.codex/agents/*.toml`
- **描述**：self-check 目前只验证 Codex Agent 文件是否存在，不验证其 `sandbox_mode` 设置是否合理（例如不检查 quality_gate 是否确实为 read-only）。
- **建议**：未来 self-check 增加字段：
  - `codex_agent_sandbox_modes_valid`：验证 4 个应只读的 Agent 确实为 read-only
  - `codex_cad_worker_scope_limited`：验证 cad_worker 的 write scope 被限制

### 4.3 CADModeling README.md 过于简略

- **位置**：`src/Modules/CADModeling/README.md`
- **描述**：该文件仅 9 行，虽然包含了模块定位和边界说明，但相比其他 Module 的详细信息（如 `docs/architecture.md` 中对 CADModeling 的描述）显得过于精简。
- **建议**：补充当前能力（SolidWorks dry-run、plate_basic_4holes 真实构建）、输入输出 Schema、模块内组件列表（agents/skills/workers/validators/reviewers）、与其他模块的关系。

### 4.4 缺少 V1.1 阶段的模板

- **位置**：`docs/version_stage_index.md`
- **描述**：当前阶段索引覆盖到 V1.0-DOCS-AGENTS 为止，V1.1 工程图阶段尚未在索引中出现。
- **建议**：可以先添加 V1.1 的预留行（目标笼统、不做什么、说明文件路径待定），避免未来忘记更新索引。

### 4.5 示例提示词可以更丰富

- **位置**：`docs/codex_agent_team_guide.md`
- **描述**：当前只有 2 个示例提示词（project_manager 和 api_researcher），缺少其他 Agent（code_mapper、cad_worker、quality_gate、docs_writer）的调用示例。
- **建议**：为每个 Codex Agent 补充至少一个典型调用示例。

### 4.6 self-check 对"Codex Agent 不替代 Module"的验证方式需要说明

- **位置**：`output/reports/platform_self_check_report.json` 中的 `codex_agents_do_not_replace_project_modules` 和 `codex_agents_respect_worker_boundaries`
- **描述**：这两个字段的值为 true，但 self-check 报告中没有说明是通过什么方式验证的（是文档声明检查？代码 grep？配置分析？）。如果这只是文档自声明，则存在文档说一套/代码做一套的风险。
- **建议**：在 self-check 实现中增加对这两个字段的验证说明（例如通过 grep 检查 .codex/agents 中的 instructions 是否包含关键词），并在报告中记录验证方式。

### 4.7 Codex Agent 调用的 Token 成本未在文档中提示

- **位置**：`docs/codex_agent_team_guide.md`
- **描述**：文档说明了"小型单文件修改不需要 spawn agents"，但没有明确说明完整 Agent Team 调用的预估 Token 消耗。
- **建议**：在 guide 中增加成本提示，帮助用户判断何时使用 Agent Team、何时直接单 Agent 执行。
