# AI Mechanical Engineer Platform

## 目标与适用范围

本仓库建设可持续演进的机械工程平台：强模型负责工程理解、规划和决策，平台负责工程约束、确定性执行、真实 CAD/API 能力与结果验收。

## 输入输出与执行步骤

输入为机械工程需求与约束，输出为受控工程计划、执行产物和验收证据。请从 [项目说明](AI_Mechanical_Engineering_Agent_Platform/README.md) 进入，并按 [中文文档入口](AI_Mechanical_Engineering_Agent_Platform/docs/index.md) 阅读当前阶段与执行协议。

## 验证标准、常见失败与禁止事项

验证命令、当前结果和失败处理以项目说明及阶段页为准。底层项目目录与解决方案继续使用 `AI_Mechanical_Engineering_Agent_Platform`，以兼容工具和既有证据路径。路径不匹配时应先核对工作目录；禁止全局替换历史路径、修改 `reviewrep` 或将模型建议视为真实 SolidWorks 验证结果。
